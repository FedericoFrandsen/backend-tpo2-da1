# Imágenes de demostración

Siete ilustraciones originales de objetos ficticios, incluidas en el repositorio para que la demo funcione sin servicios externos. No son fotos ni contienen datos personales. Los dos archivos de llaves y los dos de mochila permiten recorrer una galería real con imágenes distintas.

El seed copia las imágenes a la carpeta de uploads de cada toma y registra su propietario y tipo en la base. La app las obtiene por las mismas rutas HTTP que las imágenes subidas normalmente. La palabra de verificación «Nube» no aparece dibujada en las llaves.
